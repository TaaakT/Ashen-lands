# Ashen Lands (beta)

A 2D Souls-like action game with a pixel-art dark fantasy look. A single HTML file with no dependencies and no external assets.

**Languages:** Русский · English · Deutsch (Settings → Language)

## Run

Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root). On Android, play in landscape orientation.

## Features

- 4 classes: assassin, warrior, archer, mage; character creator (name and appearance)
- Parrying, fencing (thrust / slash / overhead strikes), stuns, weapon effects (bleed, poison, freeze)
- Bow with draw strength and mouse aiming, body-part damage multipliers
- Loot with rarities, inventory, armor slots, distinct weapon models
- 3 levels with different bosses (unlocked as you progress), an underground dungeon with a mini-boss
- Autosave at bonfires, settings menu, controls for desktop and Android

## Controls

| Action | Keyboard / mouse |
|---|---|
| Move | A / D |
| Jump | W / Space |
| Slash | J / Left mouse button |
| Thrust | U / Right mouse button |
| Overhead strike | O / Middle mouse button or Shift + Left mouse button |
| Roll | K / Shift |
| Block and parry | L |
| Flask | Q |
| Interact | E |
| Level up (at a bonfire) | R |
| Inventory and pause | I / Esc |

Archer and mage: aim with the mouse; hold the left button to draw the bow, release to shoot. On a phone, use the on-screen buttons.

## Fencing

Thrust beats overhead, slash beats thrust, overhead beats slash. Identical strikes bounce off and drain stamina; with no stamina left you are stunned. Mix your strikes to build combos.
